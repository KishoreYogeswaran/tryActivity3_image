# tryActivity3 Web App - Setup Guide

## Quick Start

### 1. Install Dependencies
```bash
cd tryactivity3_webapp
npm install
```

### 2. Environment Variables
Create a `.env.local` file in the root directory:

```bash
GROQ_API_KEY=your_groq_api_key_here
GEMINI_API_KEY=your_gemini_api_key_here
```

**Where to get API keys:**
- **Groq API Key**: Get from [https://console.groq.com](https://console.groq.com)
- **Gemini API Key**: Get from [https://makersuite.google.com/app/apikey](https://makersuite.google.com/app/apikey)

### 3. Run Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Generate Activity JSON Files
Before using the web app, generate activity JSON files using the Python script:

```bash
cd ../tryActivity3_image
python run_batch_generation.py
```

This will create JSON files in `tryActivity3Outputs/{scenarioKey}/` directory.

### 5. Use the Web App
1. Upload a generated JSON file on the landing page
2. Read the scenario and write your prompt
3. Submit for evaluation (uses Groq GPT-OSS-120B)
4. Get detailed feedback with score
5. Try again if needed (max 3 attempts)
6. View model prompt if you don't score 5/5 in 3 attempts
7. Generate and view the image (uses Gemini 3 Pro Image)

## Project Flow

```
1. Upload JSON → 2. Write Prompt → 3. Get Feedback → 4. Improve/Retry
                                                         ↓
                                            5. Generate Image (if qualified)
```

## API Routes

- **POST /api/evaluate** - Evaluates user prompts using Groq GPT-OSS-120B
- **POST /api/generate-image** - Generates images using Gemini 3 Pro Image

## Troubleshooting

### API Key Issues
- Ensure `.env.local` is in the root of `tryactivity3_webapp`
- Restart the dev server after adding environment variables

### JSON Upload Issues
- Ensure the JSON file was generated by `tryActivity3_image/run_batch_generation.py`
- Check that the JSON has required fields: `title`, `activity_scenario`, `rubrics`, `model_prompt`

### Image Not Loading
- The image is pre-generated in the JSON file as base64
- If missing, the API will attempt to generate a new one using Gemini 3 Pro Image
